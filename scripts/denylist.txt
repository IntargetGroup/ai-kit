# Extra public-safety patterns for scripts/check.mjs.
# One JavaScript regular expression per line, matched case-insensitively and with the u flag
# against every line of every tracked text file and every file path. Blank lines and lines
# starting with # are ignored.
#
# \b only knows ASCII letters, so it fails next to accented letters (a name ending in ò).
# For a word edge there, use (?<![\p{L}\p{N}]) before and (?![\p{L}\p{N}]) after the word.
#
# This file is public. Never add names of colleagues, clients or brands here: the pattern
# itself publishes the name (and check.mjs flags it, because this file is scanned too).
# Put those patterns in the CHECK_DENYLIST repository secret, one regex per line.
# CI passes the secret on push to main only, and check.mjs reports matches by file and line only.

# Seat, licence, user or head counts.
\b\d+\s*(?:seats?|licen[csz][ae]s?|posti|utenti|account)\b
\b\d{2,}\s+(?:people|persone|colleghi|dipendenti|employees)\b

# Cloud Run revision names: service name, five digits, three characters.
\b[a-z][a-z0-9-]*-\d{5}-[a-z0-9]{3}\b

# Company hosts other than the public MCP endpoint; hosted infrastructure.
\b(?!mcp\.)[a-z0-9-]+\.intarget\.net\b
\b[a-z0-9]{20}\.supabase\.co\b
\bdocker\.pkg\.dev\b

# Italian personal data: codice fiscale, IBAN (with or without spaces), mobile and landline numbers.
\b[a-z]{6}\d{2}[a-ehlmprst]\d{2}[a-z]\d{3}[a-z]\b
\bIT\d{2}\s?[a-z]\d{3}\s?\d{4}\s?\d{3}[\da-z]\s?(?:[\da-z]{4}\s?){2}[\da-z]{3}\b
\+39[\s.]?\d{2,4}[\s.]?\d{5,8}\b
