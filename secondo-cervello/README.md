# Secondo cervello

Un secondo cervello è il posto dove Claude ritrova ciò che sai, da una sessione all'altra.
Qui ci sono due varianti. Parti dalla leggera: basta a quasi tutti.

| | [Leggero](leggero.md) | [Completo](completo.md) |
|---|---|---|
| Cos'è | Una cartella di lavoro sul tuo computer + Indeck | Un archivio personale di note in Markdown, compilato da Claude, con git |
| Per chi | Tutti | Chi vuole una base di conoscenza personale costruita in mesi, da molte fonti |
| Cosa installi | Niente oltre all'app desktop di Claude | Claude Code, git; Obsidian se vuoi vedere il grafo |
| Tempo di avvio | 15 minuti | Qualche ora, più manutenzione ogni settimana |
| Dove vive la conoscenza di lavoro | In Indeck | In Indeck. Il vault contiene solo conoscenza personale |
| Punto di partenza | [inizia/README.md](../inizia/README.md) | [completo.md](completo.md) |

## Le regole che valgono per entrambe

- **Indeck resta la memoria condivisa.** Clienti, progetti, decisioni e metodi stanno in Indeck. Il tuo computer contiene i file su cui lavori.
- **Un fatto, un posto.** Una copia locale di una memoria Indeck diverge in pochi mesi. Tieni un link, non una copia. La mappa completa è in [guide/memoria.md](../guide/memoria.md).
- **Il materiale dei clienti non va in un archivio personale.** Né in una cartella sincronizzata privata, né in un repository personale.
- **Niente segreti.** Password, chiavi, dati sanitari e dati HR su altre persone non entrano in nessuna memoria.

## Hai lavorato in un'altra chat?

Una conversazione utile su claude.ai, ChatGPT, Gemini o NotebookLM si porta dentro con [prompt-export-chat.md](prompt-export-chat.md). Il risultato va in Indeck con la skill di ingestione, oppure nel `raw/` del vault completo.
